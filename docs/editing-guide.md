# 網站後台操作說明

這份說明給**不寫程式**的老師與同學。網站內容（成員、論文、消息、研究主題、聯絡資訊）都在網頁後台修改，不需要碰程式或 Git。

## 第一次使用

**不需要 GitHub 帳號。**

1. 把你的 email 告訴網站管理員，管理員會在後台邀請你。
2. 收到 Pages CMS 的邀請信後，點信裡的連結登入（之後從 https://app.pagescms.org 用同一個 email 登入）。
3. 選擇 `Prof-Shih/hcsi-lab`，就會看到左側選單：成員、論文發表、最新消息、研究主題、實驗室基本資料。

用 email 登入的人只能改內容和上傳圖片，碰不到網站程式，不用擔心改壞。

## 存檔之後

按 **Save** 後，後台會自動存進 GitHub，網站約 **2～5 分鐘**後更新。重新整理 https://prof-shih.github.io/hcsi-lab/ 就能看到。

如果 5 分鐘後還沒變，代表內容有欄位填錯，網站會**保留上一版不受影響**。請通知管理員，或回到後台檢查標示「必填」的欄位有沒有漏填。

## 常見工作

### 新增成員並上傳照片

1. 左側選 **成員** → 右上 **Add an entry**。
2. 填「中文姓名」「英文姓名」（例如 Ming-An Chen，也會成為檔名）、選「身分」。
3. 「照片」按 **Upload** 選檔案，建議正方形、500×500 以上。沒放照片會顯示姓氏頭像。
4. 其他欄位有就填，沒有可以空著。「排序」數字小的排前面。
5. 畢業時把「身分」改成 **畢業生**，並填「畢業年」「碩士論文題目」「畢業去向」，就會出現在研究所頁的學長姐區。
6. 按 **Save**。

### 新增論文並附 PDF

1. **論文發表** → **Add an entry**。
2. 填標題、期刊或會議、年份，選類型（期刊／會議／學位論文／其他）。
3. 「作者」一格填一位，按 **+** 加下一位，依作者順序。
4. 國內期刊或研討會請勾「國內發表」。
5. 有 DOI 就在「DOI 或論文連結」貼完整網址（https://doi.org/…）；「PDF」可上傳全文。
6. 得獎的話在「得獎註記」寫獎項名稱，著作頁就能用「只看得獎」篩出來。

### 發佈最新消息

1. **最新消息** → **Add an entry**。
2. 填標題、選日期；首頁會顯示最新 3 則。
3. 「內文」可以打字、加粗、插入連結或圖片；「封面圖」可不放。

### 修改聯絡資訊

左側選 **實驗室基本資料**，修改地址、研究室位置、信箱、電話後按 **Save**。頁首、頁尾、首頁和聯絡頁會一起更新。

### 把頭像換成「拉拉看」（可選）

拉拉看頭像可以在成員頁被按住拉長、放手彈回，平常還會自己眨眼、微笑。想用的人：

1. 打開對位參考圖 https://prof-shih.github.io/hcsi-lab/lala-photo-guide.svg 。
2. 拍一張**正方形、正面看鏡頭、頭不要歪**的照片：雙眼睜開、嘴巴閉起來不要笑。
3. 用修圖軟體裁切或縮放，讓**兩眼和兩個嘴角對準參考圖的紅點**（可以把參考圖疊在照片上半透明對齊）。
4. 後台 **成員** → 打開自己那筆 → 「頭像風格」選 **拉拉看**，在「拉拉看照片」上傳這張照片 → **Save**。

只選拉拉看、沒上傳照片的話，網站不會更新（維持上一版），要補上照片才會成功。不想用了就把「頭像風格」改回「一般」。

請只上傳**自己**的照片，別人的照片要先取得本人同意。

## 注意

- **刪除**是真的刪掉，刪之前確認一下。
- 不要同時兩個人改**同一筆**資料。
- 圖片請用 JPG／PNG／WebP，單張盡量小於 2 MB。
- 選單、版面、頁面結構要改的話，請找程式人員（見 README.md）。
